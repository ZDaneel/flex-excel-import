# flex-excel-import

> Config-driven Excel import engine for Spring Boot, with an Angular admin UI.

![Java](https://img.shields.io/badge/java-21-orange)
![Spring Boot](https://img.shields.io/badge/spring--boot-3.3-brightgreen)
![Angular](https://img.shields.io/badge/angular-18-red)
![License](https://img.shields.io/badge/license-MIT-blue)

**Status:** 🚧 Early development.

## What it does

Excel ingestion for enterprise backends, driven by declarative config instead of per-format code. Business users remap columns through a UI; developers only define how rows are handled.
